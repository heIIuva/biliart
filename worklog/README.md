# Worklog

Один файл на задачу: `YYYY-MM-DD-<коротко-о-задаче>.md`. Не коммитится (глобальный gitignore).
Перед работой: `grep -ri "<ошибка / код / сущность>" .claude/worklog/`.

Шаблон:

```
# <Что за задача> (<статус: сделано / откачено / открыто>)
Тикет: … · Коммиты: … · Дата: YYYY-MM-DD

## Симптомы — что наблюдалось, дословно
## Зачем — какую проблему решали, кто попросил
## Что сделано — и почему так; какие варианты отброшены и почему
## Как проверял — команды, замеры, цифры
## Почему так проверял — что эта проверка ловит и чего НЕ ловит
## Итог и грабли — что не сработало, что осталось открытым
```
